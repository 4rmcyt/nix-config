# Keycloak Secrets Template

## Required Secrets

Add these keys to `secrets/keycloak.yaml` using SOPS:

```bash
sops secrets/keycloak.yaml
```

## Secrets to Add

```yaml
# Keycloak admin password
keycloak_admin_password: CHANGE_ME_TO_SECURE_PASSWORD

# PostgreSQL database password for Keycloak
db_password: CHANGE_ME_TO_SECURE_PASSWORD

# OAuth2 Proxy client secret (from Keycloak client credentials)
oauth2_proxy_client_secret: CHANGE_ME_AFTER_CREATING_CLIENT

# OAuth2 Proxy cookie secret (base64 encoded, 32 bytes)
oauth2_proxy_cookie_secret: CHANGE_ME_TO_RANDOM_BASE64
```

## Generate Secure Secrets

Run these commands to generate secure random secrets:

### Keycloak Admin Password
```bash
openssl rand -base64 32
```

### Database Password
```bash
openssl rand -base64 32
```

### OAuth2 Proxy Cookie Secret
```bash
# Generate 32 random bytes, base64 encode them
openssl rand -base64 32 | head -c 32 | base64
```

### OAuth2 Proxy Client Secret

This will be generated by Keycloak when you create the `oauth2-proxy` client:

1. Deploy Keycloak first (without OAuth2 Proxy)
2. Log in to Keycloak admin console
3. Create the `oauth2-proxy` client (see SETUP.md)
4. Copy the client secret from the **Credentials** tab
5. Add it to `secrets/keycloak.yaml`
6. Redeploy to enable OAuth2 Proxy

## Deployment Order

1. **First deployment** (Keycloak only):
   - Add `keycloak_admin_password` and `db_password` to secrets
   - Comment out the import of `oauth2-proxy.nix` in `default.nix`
   - Deploy: `sudo nixos-rebuild switch`

2. **Setup Keycloak**:
   - Access Keycloak at `https://auth.${your-domain}`
   - Create `oauth2-proxy` client (see SETUP.md Step 4)
   - Copy the client secret

3. **Second deployment** (with OAuth2 Proxy):
   - Add `oauth2_proxy_client_secret` and `oauth2_proxy_cookie_secret` to secrets
   - Uncomment the import of `oauth2-proxy.nix` in `default.nix`
   - Deploy: `sudo nixos-rebuild switch`

## Verifying Secrets

After adding secrets, verify they're encrypted:

```bash
cat secrets/keycloak.yaml
```

You should see encrypted data, not plaintext.

To view decrypted secrets:

```bash
sops -d secrets/keycloak.yaml
```

## Rotating Secrets

To change any secret:

1. Edit secrets file: `sops secrets/keycloak.yaml`
2. Update the secret value
3. Redeploy: `sudo nixos-rebuild switch`
4. Restart affected services:
   ```bash
   sudo systemctl restart keycloak.service
   sudo systemctl restart oauth2-proxy.service
   ```

**Note**: Rotating the cookie secret will log out all users.
